Curious?
A servo is a small motor that turns to an exact angle you ask for, like a clock hand. Shaking the head is the code saying “go to 60°, now 120°, now 60°…” with a short wait in between so you can see it.

The code that does it
// when I press 7 → shake head
if (key == 7) {
  for (int i = 0; i < 3; i++) {
    pan.write(60);
    delay(200);
    pan.write(120);
    delay(200);
  }
  pan.write(90);
}
